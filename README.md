# 大橘官的精神角落

个人博客，基于 [AstroPaper](https://github.com/satnaing/astro-paper) v6.1.0。

- 站点：https://www.uniduke.ac.cn
- 文章 canonical：`/{slug}/`（`/posts/{slug}`、`/blog/{slug}` 301）
- 碎碎念：`/notes/`
- 本地 CMS：`npm run dev` → `/keystatic`

```sh
npm install
npm run dev -- --host 100.103.1.5 --port 4321
npm run build
```
